# AgriGuard AI — ML Risk Scoring Service

A FastAPI microservice that scores daily crop drought risk (0-100) for Indian agricultural districts using a gradient-boosted ML model trained on synthetic weather and soil data.

---

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Train the model (one-time)
```bash
python3 train_model.py
```

### 3. Start the API server
```bash
uvicorn main:app --reload
```

The server runs on **http://localhost:8000** (or port 8001 if 8000 is occupied).

Interactive API docs: http://localhost:8000/docs

## API Endpoints

### `POST /score` — Score a single day's readings

**Request body:**
```json
{
  "districtId": 1,
  "date": "2024-09-10",
  "rainfall_mm": 0.5,
  "consecutive_dry_days": 9,
  "temperature_c": 35.5,
  "soil_moisture_index": 0.40
}
```

**Example curl:**
```bash
curl -X POST http://localhost:8000/score \
  -H "Content-Type: application/json" \
  -d '{
    "districtId": 1,
    "date": "2024-09-10",
    "rainfall_mm": 0.5,

    "temperature_c": 35.5,
```

**Example response:**

`demo_sequence.json` contains 10 scripted readings for `districtId=1` that escalate
from a score of **~6 to 100** across a 27-day drought window. The oracle relayer

## Model Card

### What is this model?
A **scikit-learn GradientBoostingRegressor** (400 trees, max_depth=6, lr=0.04) that
predicts a 0–100 crop drought risk score given daily weather and soil readings.

### Training data
- **Source:** Entirely synthetic — generated by `synthetic_data.py`
- **Size:** ~3,250 rows across 10 simulated Indian districts, 2 growing seasons
- **Label generation:** A physically motivated formula combining rainfall deficit,
  consecutive dry-day streak (logistic), soil moisture deficit, and heat stress,
  scaled non-linearly and augmented with 200 curated extreme-event rows
- **Noise:** Gaussian noise (σ ≈ 6 points) added to labels to prevent trivial overfitting

### Features
| Feature | Description |
|---------|-------------|
| `rainfall_mm` | Daily rainfall (mm) |
| `consecutive_dry_days` | Streak of days with < 2.5 mm rain |
| `temperature_c` | Daily maximum temperature (°C) |
| `historical_avg_yield` | District average yield (tonnes/ha) |
| `current_soil_moisture_index` | Soil moisture (0=bone dry, 1=field capacity) |

### Performance
- Train R²: **0.98**
- Test R²: **0.93**
- Test MAE: **4.69 score points**

### What this model does NOT account for
- **Real meteorological data:** Labels and features are 100% synthetic. The model has NOT
  been trained on IMD (Indian Meteorological Department) or NDVI satellite data.
- **Crop phenology:** There is no crop growth stage modelling (germination, tillering,
  flowering sensitivity) — a real system would use this.
- **Spatial correlation:** Districts are treated independently; no spatial spillover.
- **Flood risk:** The current design only captures drought stress (low rainfall). High
  rainfall causing waterlogging is not modelled.
- **Market and supply chain factors:** Only biophysical risk is captured.

> ⚠️ **This is a hackathon prototype.** It demonstrates a technically sound ML pipeline
> architecture, not a deployable actuarial model. Real deployment would require at least
> 5+ years of district-level IMD, NDVI, and crop yield data validated against ground truth.
